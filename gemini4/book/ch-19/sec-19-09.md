# Chapter 19: Key File Formats, Metadata, Archiving, and Data Discovery (STAC & Beyond)

*How elevation data is encoded on disk and in the cloud, documented for posterity, discovered via modern catalogs, and preserved across decades.*

---

## 19.9 Curated Key References

The standards specifications, seminal papers, and official reports listed below establish the open architectures for raster, point cloud, and metadata encoding in digital elevation modeling.

---

### Foundational and Seminal Literature

* **Calder, B. R., Byrne, S., Lamey, B., Brennan, R. T., Case, J. D., Fabre, D., Gallagher, B., Ladner, R. W., Moggert, F., & Paton, M.** (2005). The Open Navigation Surface Project. *International Hydrographic Review*, 6(2) (New Series), 9–18.  
  *The landmark hydrographic paper introducing the Bathymetric Attributed Grid (BAG) format, mandating paired elevation and uncertainty layers within HDF5 containers.*

* **Gurtner, W., & Mader, G.** (1990). Receiver Independent Exchange Format Version 2. *CSTG GPS Bulletin*, 3(3), 1–8.  
  *The foundational specification defining the RINEX format for multi-vendor GNSS carrier phase and pseudorange data interchange.*

* **Isenburg, M.** (2013). LASzip: Lossless compression of LiDAR data. *Photogrammetric Engineering & Remote Sensing*, 79(2), 209–217. DOI: [10.14358/PERS.79.2.209](https://doi.org/10.14358/PERS.79.2.209)  
  *Derives the multi-stream predictive arithmetic coding algorithms utilized in the open-source LAZ point cloud format.*

* **Rew, R., & Davis, G.** (1990). NetCDF: An interface for scientific data access. *IEEE Computer Graphics and Applications*, 10(4), 76–82. DOI: [10.1109/38.56302](https://doi.org/10.1109/38.56302)  
  *Introduces the machine-independent Network Common Data Form (NetCDF) array architecture widely used for oceanographic and geophysical elevation grids.*

* **Ritter, N., & Ruth, M.** (1997). The GeoTiff data interchange standard for raster geographic images. *International Journal of Remote Sensing*, 18(7), 1637–1647. DOI: [10.1080/014311697218340](https://doi.org/10.1080/014311697218340)  
  *The foundational paper detailing the architecture of GeoTIFF 1.0, embedding geokeys and projection metadata directly inside private TIFF tags.*

* **Wells, D. C., Greisen, E. W., & Harten, R. H.** (1981). FITS: A Flexible Image Transport System. *Astronomy and Astrophysics Supplement Series*, 44, 363–370.  
  *The historic specification formalizing self-describing scientific image and raster array storage.*

* **Wilkinson, M. D., Dumontier, M., Aalbersberg, I. J., et al.** (2016). The FAIR Guiding Principles for scientific data management and stewardship. *Scientific Data*, 3, 160018. DOI: [10.1038/sdata.2016.18](https://doi.org/10.1038/sdata.2016.18)  
  *Establishes the Findable, Accessible, Interoperable, and Reusable (FAIR) framework for long-term scientific data archiving and persistent metadata.*

### Modern Standards and Specifications

* **American Society for Photogrammetry and Remote Sensing (ASPRS).** (2019). *LAS Specification, Version 1.4 – R15*. Bethesda, MD: ASPRS.  
  *The authoritative open binary standard for discrete 3D point cloud storage, specifying Point Data Record Formats 0 through 10.*

* **Hanson, M., Holmes, C., Mohr, M., et al.** (2021). *SpatioTemporal Asset Catalog (STAC) Specification, Version 1.0.0* (updated to v1.1.0, 2024). Radiant Earth Foundation. Available at: `https://stacspec.org/`.  
  *The core open standard defining JSON schemas for STAC Items, Catalogs, Collections, and APIs.*

* **International Hydrographic Organization (IHO).** (2023). *IHO S-102: Bathymetric Surface Product Specification, Edition 2.2.0* (and Edition 3.0.0, 2024). Monaco: International Hydrographic Organization.  
  *The international S-100 hydrographic specification governing high-resolution bathymetric navigation surfaces.*

* **Open Geospatial Consortium (OGC).** (2019). *OGC GeoTIFF Standard, Version 1.1*. OGC Document 19-008r4. Wayland, MA: Open Geospatial Consortium.  
  *Standardizes the official OGC specification for GeoTIFF tags and Coordinate Reference System encoding.*

* **Open Geospatial Consortium (OGC).** (2023). *OGC Cloud Optimized GeoTIFF Standard, Version 1.0*. OGC Document 21-026. Wayland, MA: Open Geospatial Consortium.  
  *The formal international standard codifying the internal tiling, overview pyramid structure, and HTTP Range header layout for Cloud-Optimized GeoTIFFs (COGs).*

* **Open Navigation Surface (ONS) Working Group.** (2018). *Bathymetric Attributed Grid (BAG) Format Specification, Version 1.6.3*. Open Navigation Surface.  
  *Defines the HDF5 hierarchical storage schema for coupled elevation and uncertainty bathymetric surfaces, including tracking lists and variable-resolution extensions.*
